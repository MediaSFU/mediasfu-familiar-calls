# Android WHIP/WHEP static validation evidence

`01-emulator-launch.png` was captured from the `Medium_Phone_API_36` emulator
after installing the locally assembled debug APK and cold-launching
`com.mediasfu.familiarcall.protocol.debug`.

This image proves native installation, launch, and the public onboarding UI. It
does **not** prove room creation, WHIP publishing, WHEP playback, remote media,
audible audio, or teardown. Those require a separately documented, temporary
two-participant staging acceptance run.

No credentials, protocol leases, room identifiers, or private diagnostics are
present in this evidence folder.
